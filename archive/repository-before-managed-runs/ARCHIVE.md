# Historical repository material

These files came from the repository before the managed measurement update. They
include the earlier Pascal-G pipeline, analyses, deployment alternatives and data.
They are preserved for research history; this directory is not an active runtime.
The original README is retained as README.md. The root README describes the current
synthetic measurement pipeline, which does not claim to run the old application.

The manifest records original paths, content hashes, and existing archive copies
when identical content was already retained. Generated OS/editor metadata remains
available in the original Git history and the separate verified repository bundle.
Restore individual files after checking their dependencies; do not run archived
launch scripts or deployment definitions as part of a current experiment.
