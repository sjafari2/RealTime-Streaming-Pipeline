# Paired preliminary-results tables

These tables reorganize the existing 24 trials; no experiment has been rerun.
Each repetition column shows keep-three → scheduled-scale-to-six outcomes from
separate paired trials. These are exact paired values rounded for presentation,
not ranges or before/after observations within a single run.

Total duration includes warm-up and drain: lower input and short balanced = 5 min;
sustained balanced = 12 min; distributed and single-partition skew = 7 min.
All have 1 min warm-up and 2 min drain. The source rates are 600 messages/s total
for lower input and 1,500 messages/s total otherwise.

Data retain each source record and run ID. Existing earlier single-partition
results are preserved separately from matched comparisons. Source values were
read from the previously reconciled unified-results-data.json; no outcomes changed.
